# Auth RBAC React Frontend v2

## Run

```bash
npm install
npm run dev
```

Backend should run on `http://localhost:5000`.
Frontend runs on `http://localhost:5173`.

## Backend routes used

- POST `/auth/signup`
- POST `/auth/login`
- GET `/users/me`
- GET `/users`
- DELETE `/users/:id`
- GET `/users/basic`
- GET `/users/pro`
- GET `/usage/me`
- POST `/usage/test-ai`
- POST `/nlac/check`
- POST `/payments/create`
